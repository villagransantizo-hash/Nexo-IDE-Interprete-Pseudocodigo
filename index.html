DICCIONARIO DEL LENGUAJE
Tipos de datos
05 DISPONIBLES
Declara una variable antes de utilizarla. Puedes cargar un ejemplo de cada tipo directamente en el editor.

            

              
01
EnteroNÚMERO
Números sin decimales. Ej.: edades, cantidades y contadores.
Definir edad Como Entero

02
DecimalNÚMERO
Admite fracciones y operaciones con punto decimal.
Definir precio Como Decimal
precio = 12.75

              
03
TextoCADENA
Frases y nombres escritos entre comillas dobles.
Definir nombre Como Texto
nombre = "Ana"

              
04
LogicoBOOLEANO
Solo Verdadero o Falso. Úsalo en condiciones con Y, O y No.
Definir activo Como Logico
activo = Verdadero

              
05
CaracterUN SÍMBOLO
Guarda un único carácter entre comillas simples.
Definir inicial Como Caracter

Consejos útiles

ESTRUCTURAS REPETITIVAS
Repetidores
03 CICLOS
Repite instrucciones mediante un contador o una condición. Todos los ciclos tienen límite de ejecución para evitar bloqueos.

            

              
01Para · FinPara
Repeticiones controladas por una variable numérica declarada. Paso es opcional; su valor predeterminado es 1.
Definir i Como Entero
Para i = 1 Hasta 5 Hacer
    Escribir i
FinPara

              
02Mientras · FinMientras
Evalúa la condición antes de cada vuelta. Si inicialmente es falsa, no entra al ciclo.
Mientras contador < 3 Hacer
    Escribir contador
    contador = contador + 1
FinMientras

              
03Repetir · Hasta Que
Primero ejecuta el cuerpo y después comprueba la condición. Se realiza al menos una vez.
Repetir
    intentos = intentos + 1
    Escribir intentos
Hasta Que intentos == 3

            
Seguridad
El intérprete detiene programas después de 10 000 instrucciones para evitar ciclos infinitos. Paso 0 genera un error de ejecución.
